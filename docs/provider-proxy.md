# 供应商独立 SOCKS5 代理

入口：供应商详情 → 高级设置右侧的「代理」。

- 默认关闭，地址预填 `127.0.0.1`，端口 `10808`，可修改。
- 关闭时保持默认网络行为，继承应用已有全局网络配置，仍可能经过手机 VPN；不是强制直连。
- 启用后，可连接 v2rayNG 等客户端提供的本机 SOCKS5 入口。请先启动代理客户端，并核对其实际监听端口。
- 支持无认证或 SOCKS5 用户名/密码认证。认证字段同时留空或同时填写，各不超过 255 个 UTF-8 字节。
- 点击保存才生效。测试连接使用当前表单配置请求供应商模型列表，不发送聊天生成请求，不自动保存。

## 作用范围

每个供应商拥有隔离的客户端及连接池。聊天、流式输出、模型列表、额度查询，以及由供应商实现发出的其他 API 请求均使用该网络路径。账号型供应商的应用内令牌交换和刷新同样遵循对应请求的代理配置；Google 服务账号令牌请求使用供应商客户端。

外部浏览器的登录页面不受此配置控制，可能仍需 VPN。MCP、SSH、应用更新、独立搜索服务和其他全局资源请求不受此供应商设置影响。

目标域名通过 SOCKS5 交由代理端解析；如代理地址本身是域名，为连接代理仍需要本地解析该代理域名。代理连接或认证失败不会自动转为直连。保存新配置只影响后续请求，不主动取消已开始的请求。

## 实现与安全

- 复用 ProviderManager，未新增 VLESS/VPN 核心。
- SOCKS5 握手和认证按 socket 隔离，不设置新的进程级代理或全局认证器。
- HTTPS 仍由 OkHttp 对原始目标域名执行 TLS 和证书校验，不信任所有证书。
- 本地合成路由地址只用于将目标域名传入 SOCKS5；禁用跨主机 HTTP/2 连接合并，避免合成地址导致误复用。
- 测试客户端使用独立、短超时的连接池；不把未保存的测试配置放入运行时供应商缓存。
- 切换供应商协议保留代理设置。供应商分享会移除全部代理配置，导入分享时也会清除代理配置，避免隐式改路由。
- 设置备份会包含代理凭据，保护要求与 API Key 相同；代理配置的调试字符串遮蔽用户名和密码。
- SOCKS5 本身不加密认证信息，建议连接可信本机代理。远程裸 SOCKS5 不等同于加密跨境通道。

## 验证边界

本地 socket 集成测试覆盖无认证、用户名密码、远端域名传递、HTTP 流读取、目标连接失败不直连、TLS 正确证书成功与错误域名拒绝。另有配置序列化、供应商隔离/切换、协议转换和分享脱敏测试。

尚需在 Android 真机上与 v2rayNG 联调，包括后台运行、VPN 分流及真实供应商 API 的连接测试；JVM 集成测试不替代这些验证。
