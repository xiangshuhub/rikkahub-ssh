# RikkaHub SSH v3.1.7

版本：3.1.7 / versionCode 200。Android 8.0+，包名 `me.rerere.rikkahub.ssh`。

## 新增功能

- 原生子代理：并行及后台任务、任务卡片、父子问答、分阶段工作流、有限递归、执行日志、安全检查点恢复、共享 Token/估算费用预算和 Git 工作树。
- 统一配置入口：**设置 → 模型与服务 → 子代理**。全局默认开启，派发与子工具默认免审批；普通助手默认继承，可单独禁用。管理助手始终不参与。
- 角色、模型、预算和任务管理集中配置，但子代理不会合并不同助手的工具、MCP 或工作区权限。关闭全局开关会取消活动子任务；不确定的写入不会盲目重放。
- 旧版助手专属子代理配置保留，可在全局页显式导入，不会自动覆盖全局配置。
- 新增 Claude、GitHub Copilot、Kimi Code、Meta Muse、OpenRouter 订阅账号认证，保留 ChatGPT/Grok，完善授权前台会话、令牌刷新和官方服务路由。
- 增加支持服务的用量/额度展示，区分未知、零额度、无限与金额预算；Meta 仅读取已有用量快照，不会为了查询额度创建密钥。

## 安装与升级

- 普通手机优先下载 `app-github-arm64-v8a-release.apk`。
- x86_64 设备或模拟器下载对应包；不确定时选择 `app-github-universal-release.apk`。
- 正式版沿用同一签名，旧版可覆盖升级；升级前建议备份重要聊天和设置。
- 与上游原版及 `.ssh.debug` 调试版数据独立，不会自动迁移。
- GitHub/Gitee 使用同一批 APK，附带 `SHA256SUMS`。更新检查优先 Gitee，失败回退 GitHub。

## 权限与费用提醒

普通工具全局自动批准、子代理派发及子工具信任默认开启。请使用低权限 SSH 账户；子代理可能产生额外模型调用费用。只读、父助手权限和预算限制仍保留，费用预算是估算而非账单硬上限，Git 工作树也不是安全沙箱。

订阅功能仍受服务商的账号资格、地区、接口变更和使用政策限制；额度未知不等于零。不是所有服务都提供实时额度查询。
