# SSH 工作空间专属助手

新建 SSH 工作空间保存成功后，会询问是否创建同名助手；编辑已有空间不弹出。

- **创建助手**：生成新的普通助手，绑定已保存空间，使用全局默认聊天模型。本地工具仅默认开启「询问用户」，其余默认关闭，之后仍可自行修改。SSH 文件和命令工具由空间绑定提供，不受此默认值影响。
- **暂不创建 / 关闭弹窗**：仅保存工作空间。
- 创建成功可进入助手配置，也可直接完成；不会切换已选助手或当前聊天。
- 不覆盖同名助手，不复制当前助手的管理权限、Skills 或 MCP；同一弹窗的重复提交/重试使用同一个助手 ID。
- 此默认值仅用于新建 SSH 专属助手，不迁移已有助手，不改变普通助手或应用管理助手的规则。「询问用户」不是高风险命令的强制审批机制。
- 创建失败可以重试或跳过，不回滚已保存的工作空间。

默认提示词可编辑，只有一句：

> 你是此 Linux 工作空间的运维与开发助手，遵循环境和项目约定完成任务。

## 环境信息

创建助手只写本地设置，不额外连接 SSH。工作空间原有的保存前连接测试、主机指纹确认和连接失败后仍然保存的流程保持不变。

首次发送对话请求时，复用工作空间请求转换器读取远程 Shell、发行版、架构和执行用户。架构和用户使用只读的 `uname -m` / `id -un` 获取，不读取完整环境变量，不扫描项目目录，不修改远程系统。

这些信息只加入当次模型请求上下文，不写死到助手提示词。缓存按工作空间和连接配置隔离，成功结果 15 分钟后刷新，连接失败结果缓存 1 分钟。部分信息读取失败则省略，连接不可用时提供提示。

进入具体项目后，引导模型按需读取 AGENTS.md / README，遵循项目约定；不预先扫描整台设备。

## 验证

单元测试覆盖助手默认值、独立身份、简短提示词、环境解析及缓存刷新；仍需在设备上验证创建/跳过/配置入口，以及真实 SSH 对话中的环境探测。此功能不会改变普通工具的审批策略。
