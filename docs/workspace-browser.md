# 文件浏览位置与目录收藏

- 工作空间入口、聊天文件入口统一恢复该工作空间最后一次成功列出的目录，不再用聊天的 cwd 覆盖文件浏览位置。
- 保存位置包括区域（工作空间 FILES / 根目录 LINUX）和区域内的相对路径，现有区域导航不变。
- 首次打开使用工作空间目录。恢复失败时提示并尝试工作空间目录；如果后者也加载失败，保留持久化的旧位置，避免离线状态清空历史。
- 普通导航和刷新仅在列目录成功后保存位置；取消的旧请求不得覆盖新请求。
- 顶部“收藏夹”支持收藏当前目录、修改名称、移除收藏和打开目录。同一区域、同一路径只保留一条收藏。
- 收藏按工作空间 ID 隔离；打开失败显示现有文件加载错误，不自动删除收藏。移除收藏不删除服务器目录。
- 数据存放在 App 私有 SharedPreferences `workspace_browser`，不包含 SSH 凭据。历史与收藏不会改变助手绑定、聊天执行 cwd 或后端访问权限。
- 此功能不是会话或远端执行状态恢复；不重新打开文件，不新增服务器操作权限。
